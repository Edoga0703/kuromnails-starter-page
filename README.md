Crea una página web en blanco para un estudio de uñas llamado Kuromnails. Solo necesito una estructura mínima y básica con un título y un fondo oscuro. No te preocupes por el diseño ni agregues secciones complejas, ya que reemplazaré todo el código conectándolo a mi propio repositorio de GitHub

